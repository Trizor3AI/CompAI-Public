# Grok licenses and source information

CompAI includes Grok Build 1.0.62. You do not need a separate source download to use the plugin.

This folder contains:

- `LICENSE.txt`: the full Apache-2.0 license declared by the official Grok 1.0.62 Windows package.
- `THIRD_PARTY_NOTICES.md`: the unchanged notice supplied with that exact package.
- `THIRD-PARTY-NOTICES.upstream-2bdd1d6.txt`: additional upstream attributions, retained unchanged from public source commit `2bdd1d6a6369de0e8c68132ea4539e9abd9e14a8`. This broader reference is not a verified inventory of every component in Grok 1.0.62.
- `LICENSE-MPL-2.0.txt`: the Mozilla Public License for the identified MPL-covered components.

No positive evidence of missing provider modifications was found; the review has not independently proved their absence. That uncertainty is distinct from a confirmed missing-source finding.
